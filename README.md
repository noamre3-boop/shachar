# שחר

אב-טיפוס לעוזר AI ולמידה במכללה: שיחה פתוחה, קורסים קצרים בתוך הצ׳אט (מבחן רמה, משחק, שאלות אמריקאיות ופתוחות, סגנון אישי), זיכרון לכל משתמש, ורדאר לזיהוי מוקדם של סטודנטים בסיכון. כל הנתונים באתר סינתטיים.

- כניסה עם Google (Firebase Auth) או כאורח. הזיכרון נשמר במכשיר.
- מודל השפה רץ על המחשב של המשתמש דרך ComfyUI (Qwen3-VL 4B), אחרי לחיצה על "חיבור למודל במחשב שלי". ComfyUI צריך לרוץ עם `--enable-cors-header "*"`. בלי מודל, שחר עונה מתוך המקורות ומדרג תשובות לפי נקודות מפתח.
